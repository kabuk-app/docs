# Kabuk documentation

The source of kabuk.app/docs, the user documentation for Kabuk.

Kabuk is a free, open-source SSH client. Your data is encrypted on your own devices, and you
do not need an account. It is early and has not been released yet. These pages are short
placeholders in English, Turkish, Kazakh and Russian, and will grow with the app.

## Running it locally

You need [bun](https://bun.sh).

    bun install
    bun run dev
